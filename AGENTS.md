# Древо: работа с продуктом

Это публичный набор инструментов и навыков для генеалогического исследования. Семейное дело пользователя хранится отдельно от этого репозитория.

- Исследование: сначала `skills/genealogy-research/SKILL.md`. Визуализация: `skills/family-tree-studio/SKILL.md`.
- Перед новым поиском читать существующее дело, вопросы и журнал. Продолжать его, не начинать дубликат.
- Запись источника, утверждение и вывод — разные сущности. Ни число совпадений, ни CLI audit не доказывают родство.
- Реестр `registry/resources.json` описывает маршруты и проверенные пределы доступа. Он не является набором работающих API-коннекторов. Не называть недоступность отсутствием записи.
- Реальный поиск требует браузерного инструмента в среде агента. Инструмент plan только готовит очередь. Не утверждать, что выполнил поиск, если составлен только план.
- Оригиналы документов сохранять неизменными; OCR и изображения для просмотра — отдельные производные файлы. Имена и даты сверять по оригиналу.
- Платёж, отправка запроса и публикация семейного дела выполняются в пределах явного поручения. Обычные разрешённые открытые проверки продолжать самостоятельно.
- В репозиторий добавлять лишь вымышленные примеры и разрешённые компоненты с лицензиями. Фотографии могил и архивные сканы имеют собственные права; открытый просмотр не разрешает их переиздание.
- Обновлять дерево через явные assertions, `tree-preview` и проверку `diff.details` перед `tree-apply`. Для публичной проекции нужны разрешения людей, утверждений и источников; одна метка человека не разрешает все его события.
- При изменении поведения запускать подходящие проверки; полный релизный набор — `npm run verify` и браузерная проверка новой сборки. Не объявлять формальную проверку свидетельством истинности исследования.

Документация и самостоятельный код проекта написаны с помощью ИИ и проверены человеком/агентом по описанным тестам. Проверку находок и ответственность за окончательные генеалогические выводы автоматизация не заменяет.
