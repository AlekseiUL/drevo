# Изменения

## 0.3.0 — 2026-11-11

- Карточка человека стала досье: обзор жизни и деятельности, галерея материалов и все связанные исследовательские находки с их статусами.
- Локальный редактор `dossier <папка-дела>` сохраняет тексты, файлы и ссылки из браузера в частное дело. Подписи можно исправлять; удаление из карточки сохраняет оригинал.
- Фото, PDF, текст, аудио/видео доступны для просмотра; прочие разрешённые документы — для скачивания. Файлы до 20 МиБ хранятся неизменными с SHA-256.
- Перед сохранением проверяется версия дела, предыдущий JSON сохраняется в `working/dossier-history/`. Публичные разрешения разделены для текста, описания материала и самого файла.
- Выбранные вложения входят в собранный viewer; приватные файлы и произвольное содержимое папок не копируются. Демо содержит только авторские вымышленные материалы.

## 0.2.0 — 2026-11-11

- Дело и дерево связаны: явные утверждения о родстве/событиях, предпросмотр с полями до/после, сборка новой версии и откат отображения. Устаревший предпросмотр не применяется, прошлые версии сохраняются.
- Кнопка «Почему эта связь?» показывает основания каждого отношения отдельно: источник, локатор, прочтение, аргументы, противоречия, ограничения. Разные родители могут иметь разные статусы.
- План содержит три следующих действия, учитывает контекст события и историю проверок. Полный резерв доступен через `--all`; один отрицательный запрос не исключает весь сайт.
- Три браузерных маршрута проверены до реальной карточки: memorial-map и pomnim-online с фотографией; ГААО до карточки архивного дела. Образы ГААО требуют входа и не проверены.
- Публичная проекция разрешает данные по людям, утверждениям и источникам. Сводные даты человека автоматически не публикуются. Вымышленные демонстрационные данные остаются отдельными от частного дела.
- Сохранена совместимость прежних JSON и viewer `families/relationships`. Добавлены проверки полного цикла, конфликтов, кандидатов, публичных полей и браузерного поведения.

## 0.1.0 — 2026-11-11

Первый публичный выпуск: два навыка, профессиональная методика, реестр 40 ресурсов, интервью/журнал/свидетельства, структурный audit и самостоятельный интерактивный viewer с карточками-листьями и плавными ветвями. Собственный код MIT; лицензии Golos Text и Lucide сохранены.
