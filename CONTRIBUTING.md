# Как улучшать Древо

Полезнее всего реальные исправления: новый проверенный архивный маршрут, точные пределы коллекции, ошибка работы с доказательствами или нечитаемая связь дерева.

Для источника добавьте карточку в `registry/resources.json`: типы записей, географическое покрытие, бесплатную часть/платный маршрут, условия входа, дату, первичные ссылки и честный статус проверки. `verified` относится к прочитанной странице; это не обещание именного поиска. Региональная коллекция не должна отмечаться как покрывающая всю страну. `regionParents` расширяет поиск от региона к стране, не обратно.

Для изменения кода опишите проблему и наблюдаемое поведение. Запустите `npm run verify`; для интерфейса откройте свежую сборку в браузере. В тестах используйте только вымышленные семьи. Проверка UI должна учитывать гипотезы, разные виды связей и несвязанные ветви.

Не отправляйте в issues/PR паспорта, настоящие частные семейные дела, контакты живых людей или платные сканы. Для воспроизведения ошибки сократите данные до вымышленного примера. Новый сторонний компонент требует ссылки на автора, точной лицензии и сохранения обязательных уведомлений.
