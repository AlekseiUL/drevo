# Проверенные маршруты в браузере

Три маршрута переводят каталог ресурсов в конкретные действия агента. Они описывают наблюдавшийся интерфейс и сохраняемый результат, а не скрытый API или гарантированный доступ. Проверка выполнена **11 ноября 2026 года** через отдельный контекст Chrome DevTools: без входа, регистрации, оплаты и внешних сообщений. Playwright не запустился из-за занятого профиля; это отмечено как ограничение инструмента, не ошибка сайтов.

| Ресурс | Пройденный путь | Наблюдавшийся результат | Что ещё не доказано |
|---|---|---|---|
| [Карта захоронений](../skills/genealogy-research/references/browser-routes/memorial-map.md) | Запрос из примера сайта → выдача → карточка → видимое фото | Одна карточка и её фотография открыты без входа | Полнота базы, все фильтры, родство, точность всех надписей |
| [Помним Онлайн](../skills/genealogy-research/references/browser-routes/pomnim-online.md) | Форма ФИО → выдача → карточка исторической личности → фото | 4 результата запроса, одна карточка и фотография просмотрены | Доступ ко всем записям, расширенные фильтры, отсутствие будущей CAPTCHA |
| [ГААО](../skills/genealogy-research/references/browser-routes/dvinaland.md) | Публичный каталог → фонд → опись → карточка дела | Шифр, период и листаж дела доступны | Изображения и их наличие; для просмотра/заказа предложен вход |

Структурированное описание: [registry/browser-routes.json](../registry/browser-routes.json). Публичные записи использованы только для проверки механики. В репозитории нет их фотографий, полных страниц, личного семейного дела или сеансовых ссылок.

## Как использовать

1. В плане есть подходящий ресурс — прочитайте его `routeFile`. Проверьте дату маршрута и текущий интерфейс.
2. Заполните поля из семейного дела. Не подставляйте проверочный пример вместо своего вопроса и не считайте действие выполненным до наблюдения результата.
3. На каждом переходе проверяйте адрес/заголовок и обновляйте snapshot. Элементные UID временные; они не входят в переносимый маршрут.
4. Сохраняйте постоянную ссылку карточки, точный запрос/фильтры, архивный локатор, дату и охват. Изображение сверяется визуально; индекс и надпись могут расходиться.
5. Закрывайте шаг отдельным кодом результата. Один сайт может дать найденную карточку и одновременно потребовать вход для образов — это два разных этапа.

## Коды результата и журнал

| Код маршрута | Что наблюдалось | Запись в основном журнале |
|---|---|---|
| `record-found` | Открыта публичная именная карточка | `found`; подтверждено только содержание карточки |
| `image-visible` | Фото видно и осмотрено в браузере | `found`; отдельно указать объём прочитанной надписи |
| `catalog-entry-found` | Открыта карточка архивной единицы | `found`; отметить «листы не просмотрены», если это так |
| `empty-results` | Поиск завершился пустой выдачей | `not-found` только в указанном индексе/фильтрах |
| `image-unavailable` | В открытой карточке нет доступного фото/показана заглушка | `not-found` для фото в этой карточке; это не отсутствие захоронения |
| `auth-required` | Следующий шаг требует входа | `blocked` для зависимого шага; найденный каталог не обнуляется |
| `captcha-required` | Появилась CAPTCHA | `blocked`; пользователь решает её сам |
| `access-blocked` | Сайт явно отказал в доступе или вернул ошибку | `blocked` с наблюдённой ошибкой и URL |
| `tool-unavailable` | Не удалось запустить браузерный инструмент | `not-searched`; сайт этим не проверен |

Коды не являются оценкой достоверности родства. Не превращайте `record-found` в `concluded`. У `empty-results` обязательно описание охвата; у ошибки инструмента нет основания говорить об отсутствии страницы.

## Существенные наблюдения

- В Карте захоронений оболочка страницы появилась раньше результатов; нужен признак завершившейся выдачи. Фото видно в браузере, даже если accessibility snapshot не показывает отдельный image-узел.
- В Помним Онлайн запрос не изменил `/search`; для воспроизводимости нужны значения формы, а не только URL. Форма бесплатного поиска и предложение оставить заявку — разные действия.
- В ГААО первоначальный прямой переход открыл авторизацию, но обычная публичная навигация через каталог затем дала фонд, опись и дело. Это наблюдение не обещает доступ при любой блокировке. Открытая карточка дела предложила войти для содержимого; сканы не были объявлены доступными.
- Вологодский портал в запасной проверке дал `ERR_EMPTY_RESPONSE`; полноценный маршрут по нему в эту версию не включён.

При препятствии сохраните прогресс и используйте независимый подходящий бесплатный путь. Не обходите CAPTCHA, авторизацию или ограничения сервиса; покупка доступа — отдельное конкретное решение, а не автоматическая реакция на ошибку.
