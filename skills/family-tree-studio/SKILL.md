# Древо: визуальная история семьи

Используй этот пакет, когда человеку нужно увидеть родственников и связи в браузере. Код и шаблон находятся внутри `assets/viewer/`; требуется Node.js 20 или новее. Внешние сервисы для показа не нужны.

1. Найди основной персонаж и уже известные сведения. Уточняй только недостающие данные, влияющие на конкретную связь. Сохраняй разные версии имён и дат в исследовательских заметках, не выбирая одну без основания.
2. Подготовь `family.json` по [формату](references/data.md). У каждой связи свой статус доказанности. Совпадение фамилии и отчество сами по себе не устанавливают родителей. Неприсоединённый человек может оставаться отдельным листом.
3. Создай отдельную папку: `node <skill>/scripts/create-project.mjs --out <папка> --data <family.json>`. Без `--data` появится вымышленный пример.
4. В новой папке запусти `npm run dev`. Порт меняется через `npm run dev -- --port 4180`. Предъяви человеку имена, даты и отношения для исправлений; не объявляй результат доказанным только потому, что линии успешно нарисованы.
5. Если нужны фотографии, добавляй предоставленные изображения в `public/assets/photos/` с происхождением `original`, `selected` или `generated`. Этот навык не генерирует портреты. Воображаемое изображение всегда подписывается как воображаемое и не подтверждает внешность предка.
6. `npm run build` выпускает сайт в `dist/`. Данные публичных карточек, включая живых людей, входят в него. Перед размещением настоящей семьи подготовь согласованный состав; частные документы и исходники остаются вне сайта.

Проверь в браузере поиск, выбранного человека, разные поколения, путь к родственнику и отдельного несвязанного кандидата. Опека не должна стать происхождением, усыновление — биологической связью, гипотеза — установленным фактом. Пунктир и пояснение сохраняются при подсветке.

Для проверки самого пакета: `node <skill>/scripts/self-check.mjs`. Она использует только синтетические данные. Оформление декоративно напоминает растение, но источником связей остаётся исключительно JSON.
