# Мой семейный сайт

Эта папка — самостоятельный просмотрщик «Древо». Нужен Node.js 22 или новее; установка npm-пакетов не требуется.

```sh
npm run dev      # локальный просмотр; адрес появится в терминале
npm run build    # готовый статический сайт в dist/
```

На хостинг загружайте только содержимое `dist/`. Открывается `index.html`; сайт работает и в подпапке домена. `data/family.json` задаёт людей и связи, `public/assets/` хранит выбранные изображения и материалы. В сборку попадут только файлы, на которые ссылаются карточки.

Карточки расположены по поколениям. На телефоне двигайте дерево одним пальцем, меняйте масштаб двумя; «Всё древо» показывает общий обзор. Тап по человеку открывает досье. Перемещение и масштаб не меняют родственные связи.

## Дополнения от родственников

Форма по умолчанию выключена. Настройте `src/feedback-config.json` в этой отдельной папке сайта: выберите FormSubmit для доставки на почту или собственный HTTPS-приёмник. Проверьте доставку на свой адрес, включите `ready` и повторите `npm run build`. Секреты почты и токены ботов в клиентский конфиг не добавляются.

[Пошаговая установка, настройка формы и обновление сайта](https://github.com/AlekseiUL/drevo/blob/main/docs/sharing-feedback.md).

Сообщение сначала получает владелец. Сведения добавляются в исследовательское дело после проверки, затем выпускается обновлённая версия сайта. Форма сама не меняет дерево. Для редактирования досье на своём компьютере используйте команду `dossier` из полного продукта.

Размещённые файлы доступны посетителям сайта, включая `tree.json` и вложения. Согласуйте состав семейных сведений до публикации; при необходимости настройте вход на стороне хостинга. Не публикуйте частное дело, `.drevo/` или папку оригиналов целиком.
