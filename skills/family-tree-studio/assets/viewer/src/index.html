Каждая ветвь — связь.
У каждой связи — основание.

Нажмите на лист с именем, чтобы открыть историю и источники. Перетащите свободное место для перемещения. Ctrl или ⌘ вместе с колесом меняют масштаб; на телефоне используйте кнопки масштаба.

Пунктирная охристая ветвь — гипотеза. Подсветка пути не доказывает родство. Опека исключена из линий предков и потомков, усыновление помечено отдельно.

Фоновые листья и ствол служат украшением. Реальные связи рисуются только между карточками. Отсутствие фото не означает отсутствие сведений; серый цвет не означает смерть.
