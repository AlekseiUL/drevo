# Демонстрационное древо

В корне продукта запустите `npm --prefix viewer run dev`, затем откройте `http://127.0.0.1:4173`. Для другого порта: `npm --prefix viewer run dev -- --port 4180`.

Вы увидите вымышленную семью Листовых: листовидные карточки, плавные ветви, разные поколения и отдельного кандидата. Поиск, перемещение, масштаб, мини-карта и панель источников работают локально. В меню связей доступны предки, потомки и путь между людьми. Опека, усыновление и гипотезы имеют явные обозначения.

Кнопка **«Почему эта связь?»** открывает утверждение, точный локатор, прочтение источника, объяснение и противоречия. Она доступна в карточке, в цепочке пути и на самой ветви (в том числе через Tab и Enter). У двух родителей одного ребёнка могут быть разные основания. В демо все свидетельства вымышлены; ссылки `example.invalid` специально не обозначают настоящие документы.

У сведений о самом человеке, например о рождении, есть отдельная кнопка оснований. Открытое противоречие остаётся видимым даже у линии с документальной меткой: наличие документа ещё не разрешает расхождение.

`npm --prefix viewer run build` создаёт публичное демо в `viewer/dist/`. Обёртка принимает только шаблон с `fictional:true` и `demo:true`. Папка `viewer/.demo/` пересоздаётся при каждом запуске: не храните в ней своё исследование.

Для собственной семьи создайте отдельный проект через `skills/family-tree-studio/scripts/create-project.mjs --out <папка> --data <family.json>` и работайте в нём. Формат описан в `skills/family-tree-studio/references/data.md`. Сборка включает публичные имена, даты и фото, поэтому настоящую семью размещают только в согласованном составе.

Сервер слушает `127.0.0.1` и обслуживает исключительно подготовленный `dist/`; исходные данные, код сборщика и `private/` через него не доступны. Нет npm-зависимостей, внешних CDN и запросов к сервисам изображений.
